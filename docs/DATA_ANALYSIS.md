- 구어체·키워드 변형이 실제 사용자 말투("공짜로 부쳐?", "보딩 시작")와 가까워 말 바꿈에 강해졌습니다. 효과는 `docs/RAG_PARAMETERS.md` 참고 (Dense 1위 적중률 0.824 → 0.941).
- **기관이 달라도 원문 질문이 같은 경우**가 8종 있습니다. 특히 "환불은 얼마나 걸리나요?"는 **7개 기관**에 똑같이 있습니다. 기관을 밝히지 않으면 어느 기관 답인지 모호합니다.

## 8. 남은 공백 (데이터 추가 후보)

1. **대한항공 취소·환불**: v1 부터 비어 있고, 가장 많이 물을 질문입니다.
2. **해외 항공사의 한국 출발 기준 규정**: 미국 출발 조건 답변이 많아 한국 승객에게 맞지 않을 수 있습니다.
3. **숙박 체크인·부대시설·조식** 같은 운영 질문: 숙박업체 자료가 취소·환불에 쏠려 있습니다.
4. **유나이티드·루프트한자·아고다 공식 출처**: 해당 기관 자료가 모두 비공식입니다.

## 분류 방법
- 주제는 원문 질문 + '다른 표현' 변형에 키워드 규칙(`eval/analyze_data.py` 의 `RULES`)을 적용하고, 애매한 11건은 수동 판정했습니다 (`OVERRIDE`).
- "공식 출처"는 URL 이 해당 기관 공식 도메인(하위 도메인 포함)일 때입니다. 기준 도메인은 `backend/src/main/resources/application.yml` 의 `official-domains` 와 같습니다.
- "불확실 표현"은 답변에 "정리글", "정리가 있습니다", "확인되지 않", "글마다" 같은 문구가 있는 경우입니다.
